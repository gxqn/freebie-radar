# 深色主题与 favicon 设计

用户委托主助手安排 Gemini 4hy 开发、独立审核、最终验收并直接上线。

## 目标与范围
- 保留现有首页未提交改动；补齐浅色/深色手动切换，默认浅色，使用已有 radar_theme 保存选择。
- 初次绘制前应用已保存的主题，避免深色刷新闪白。存储不可用或值非法时安全回退浅色；不覆盖 html 的其他 class。
- 深色覆盖首页、侧栏、列表、详情、筛选、弹窗及管理页，保证选中按钮、状态、输入和文字对比度。
- favicon 使用用户提供的 AI 橙黑圆盘图片生成静态 PNG/ICO 多尺寸，不重绘、不引入图片生成服务。
- 不修改后端、数据库、密钥、采集频率和推送设置。

## 方案比较与选择
1. 推荐并采用：沿用现有 React/Tailwind CSS 变量体系，增加深色变量与少量语义按钮颜色修正；减少依赖与回归。
2. 逐组件复制 dark 类：变更面大且容易漏掉现有管理界面，不采用。
3. CSS 整页反色滤镜：会损坏图片和状态色，不采用。

上述默认由主助手依据用户委托选定。主题入口沿用现有太阳/月亮按钮，提供随目标主题变化的中文可访问名称。

## 验收与发布
- 主题逻辑测试、全套现有测试、TypeScript/Vite 构建。
- 浏览器检查两种主题、刷新持久化、移动布局、按钮及弹窗对比度；检查 favicon 尺寸/请求。
- Gemini 开发与独立审核，主助手复核；验收通过后仅使用既有前端 Pages 发布脚本，验证 https://zoomzero.pages.dev 的资源和主题行为。
- 如 Gemini 再报 upstream_error 无可用账号，先暂停开发并收集错误来源证据，不盲目重试或宣称已修复。
